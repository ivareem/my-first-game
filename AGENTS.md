## Working agreement

Use plain language and work one checkpoint at a time. Read `game-brief.md` and `project-state.md` before editing. Keep this learner game separate from the course repository and from any website project.

The first version uses static HTML, CSS, and JavaScript. Preserve the solo battle-for-a-square mechanic, the fixed counter rules, and complete restart behavior. Follow the blue-and-orange palette and create original, family-friendly animated aliens without copying recognizable characters. Keep accounts, databases, multiplayer, remote scores, paid services, and external asset libraries out of the first version.

Before changing behavior, identify the current version and one observable completion check. Record actual checks as Passed, Failed, or Not tested. Code inspection is not a browser test, and a local result is not evidence of a published result.

Local drafts do not authorize commits, pushes, deployments, or publication. Confirm the exact destination and version before any release action. Update `project-state.md` at each checkpoint and before handing the project to another assistant.
